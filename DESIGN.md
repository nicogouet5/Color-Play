# Color-Play × Ripley · current prototype

## Surface
Operate-mode kiosk inside the retained concept / fixture showcase. This is a functional extension of the existing retail prototype, not a new landing-page art direction. No old pitch deck or dossier is the visual authority.

## Visual authority
The supplied v2 brand playbook wins: Color-Play magenta#A8115F, pink#E6338A, Ripley plum#741472, yellow#FFD400, red#C8102E, grey#CFD4D8 and dark#16121C. Ripley's unchanged logo identifies the recipient, not an endorsement. Keep the existing Color logo and Simple Tech/UDD mark, Manrope, real project concept renders and reference clothing photographs.

## Composition
Concept introduction → discovery / pilot / embed proposal → two-mode interactive kiosk → retained3D fixture explorer. The operating UI has one primary action per state, sentence-case labels, opaque white fields and plum mode selection. No new generic dashboard or fake real-time chart.

The kiosk opens with two equal, whole-panel buttons: first visit on the left (“Quiero ver qué me podría quedar bien”) and returning shopper on the right (“¿Qué hay de nuevo para mí?”). These entry choices use the user-requested Spanish copy; the rest of the existing UI remains in English. RUT/consent appears only after selection. At600px and below the choices stack, first visit first. Back restores focus to the chosen panel; reset and idle/visibility cleanup restore the two-option screen.

The material unique to this product is the garment reference, its named target color, size and aisle, then its own printable QR. Color labels may differ from reference photos; the difference is disclosed.

## Tokens and states
Use existing Manrope fonts locally. Body16px;14px secondary notes.44px minimum touch controls, explicit focus, stable labels, role=alert errors and polite status. Size hiding removes the selected-value control as well as its output. Simulated checkout requires a known ticket and at least one selected garment; a used ticket cannot produce another local receipt.

## Motion
Retained rack rotation and optional auto-orbit, reduced-motion support and existing control feedback. No additional decorative loop or ASCII from the retired presentation.

## Responsive and print
Natural vertical flow at 320/390/768/1024/1440px. Mobile results stack; no clipped kiosk panel. The print action produces the ticket only, with a real QR, clear demo/non-redeemable warning and no RUT. A5 print preview is a browser demonstration, not a thermal-printer driver.
